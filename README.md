# Neural Language Modeling: RNNs and Transformers

**Course:** CIS 5300 / HW5  
**Artifact type:** Course project / coursework

## Overview

Implemented character-level RNN and Transformer language models within a course framework, including causal masking, scaled dot-product attention, multi-head attention, residual connections, and autoregressive generation. The project uses Tiny Shakespeare to examine language generation and attention behavior.

## Guiding question

How do recurrent and attention-based architectures model character sequences, and what failures remain with limited context and capacity?

## Methods and technical scope

PyTorch; character tokenization; causal attention; language modeling.

## Evaluation and analysis

Analyze generated text for repetition, invented words, grammatical errors, and inconsistent character names. Inspect attention patterns across heads and layers.
